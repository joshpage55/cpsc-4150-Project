## Prompt 1

What is the best way to structure a teacher-facing story builder flow for our existing Flutter app?

I used the AI to outline a clear teacher workflow around student selection, reading level, interest topic, preview, and approval. I kept the structure simple and rejected a more complicated multi-step wizard that would have felt too heavy for this milestone.

## Prompt 2

How can I make the pronunciation practice screen feel more child-friendly and easier to understand?

I used the AI for ideas about larger tap targets, clearer states, and more encouraging feedback. I kept the larger microphone-style action and clearer listening state, but I rejected some overly decorative suggestions that would have made the screen feel cluttered.

## Prompt 3

How should I frame the milestone 3 scope so it is realistic and honest rather than overpromising?

I used the AI to help turn the feature work into a locked PRD-style plan. I kept the tone candid by documenting what was implemented and what still needed live validation instead of pretending everything was fully proven.

## Prompt 4

Can you help me write a DMMT self-evaluation that is useful and not overly inflated?

I used the AI to organize the feedback around real usability issues and to phrase the evaluation in a balanced way. I kept the assessment honest by noting where the experience improved and where it still needed more testing.

## Prompt 5

Why might the app still fail to launch or authenticate correctly even when the code looks right?

I used the AI to narrow the problem to environment and runtime issues rather than assuming the bug was purely in the app logic. I kept the debugging focus on build/runtime configuration and rejected the idea that Firebase auth problems were automatically caused by a UI bug.

## Prompt 6

How should I document the story and game flow for the milestone 3 readme?

I used the AI to shape the documentation around the actual implemented experience: story generation, teacher approval, student reading, and the game path. I kept the write-up practical and transparent about the current status rather than describing the features as fully polished.
